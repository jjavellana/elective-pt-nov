# elective-pt-nov
Elective Mini System Student Records

Instructions:

~ Place Folder: Extract student_system from the ZIP into C:\xampp\htdocs\ (overwrite existing files when prompted).
~ Import Database: Start Apache and MySQL in XAMPP, open http://localhost/phpmyadmin, click Import, select or drag the school_db.sql, and click Import. (no additional settings)
~ Test in Browser: Open http://localhost/student_system/form.html, add a student, and confirm it redirects to view.php with the confirmation banner and working Update/Delete links.
~ Feel free to modify or improve the code.
